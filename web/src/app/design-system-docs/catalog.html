06 · Diálogos

Una pausa, solo cuando hace falta.

Las decisiones que descartan trabajo requieren contexto y una salida clara. Escape cierra el diálogo y devuelve el foco al botón de origen.

07 · Desarrollar

Una sola forma de construir juntos.

Importa desde design-system, compón con sus componentes y utiliza tokens para el layout.

Empieza con los componentes

Ejecuta npm run ds:check. El build y CI rechazan controles sin Design System, estilos visuales independientes e imports internos.
