# `docs/c4/`

Las vistas C4 de contexto y contenedores del MVP están en el informe de
arquitectura, §9.4–9.5. Spring Modulith genera además, en cada build,
diagramas C4/UML reales a partir del código (`ApplicationModulesTest`,
capítulo 2.2 de la guía) en `backend/target/spring-modulith-docs/`. Este
directorio guarda las versiones que el equipo decide congelar para la
documentación (por ejemplo, al cierre de cada sprint).
